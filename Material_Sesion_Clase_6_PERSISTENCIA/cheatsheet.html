Anotaciones y clases clave

@Configuration
@EnableWebSecurity
@Bean
UserDetailsService
BCryptPasswordEncoder
SecurityFilterChain
  • @Configuration: clase que configura Spring.
  • @EnableWebSecurity: activa el login.
  • @Bean: registra un objeto para que Spring lo use.
  • SecurityFilterChain: define reglas de acceso.

Thymeleaf con Security

<html xmlns:sec="http://www.thymeleaf.org/extras/spring-security">

<div sec:authorize="hasRole('ADMIN')">...</div>
<div sec:authorize="hasRole('USER')">...</div>
<div sec:authorize="isAuthenticated()">...</div>

Errores comunes

  • 403 Forbidden: tiene login, pero no el rol necesario.
  • 302 loop en /login: no agregaste .permitAll() a la ruta de login.
  • sec: no funciona: falta thymeleaf-extras-springsecurity6 o el namespace xmlns:sec.
  • Password error: no usaste BCryptPasswordEncoder para cifrar.
  • Grafico vacio: el controlador no pasa los conteos con model.addAttribute.
  • findBy... no funciona: el nombre del metodo no coincide con el campo de la entidad.
