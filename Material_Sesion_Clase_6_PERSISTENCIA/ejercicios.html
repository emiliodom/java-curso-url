Ejercicio 1 — Agregar dependencias

Agrega las 2 dependencias nuevas al pom.xml:

<dependency>

Antes de continuar
Ejecuta ./mvnw clean y ./mvnw spring-boot:run. Veras que Spring bloquea todo con un login por defecto.

Ejercicio 2 — Crear SeguridadConfig

Crea el archivo en configuracion/SeguridadConfig.java:

package com.tugrupo.tuapp.configuracion;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.*;
import org.springframework.security.config.annotation.web.configuration.*;
import org.springframework.security.core.userdetails.*;
import org.springframework.security.crypto.bcrypt.*;
import org.springframework.security.crypto.password.*;
import org.springframework.security.provisioning.*;
import org.springframework.security.web.*;

@Configuration
@EnableWebSecurity
public class SeguridadConfig {

  @Bean
  public SecurityFilterChain filtro(HttpSecurity http)
      throws Exception {
    http
      .authorizeHttpRequests(auth -> auth
        .requestMatchers("/","/css/**","/login").permitAll()
        .requestMatchers("/admin/**","/recursos/borrar/**",
            "/recursos/estadisticas").hasRole("ADMIN")
        .anyRequest().authenticated()
      )
      .formLogin(form -> form
        .loginPage("/login")
        .defaultSuccessUrl("/recursos", true)
        .permitAll()
      )
      .logout(logout -> logout
        .logoutSuccessUrl("/login?logout")
        .permitAll()
      );
    return http.build();
  }

  @Bean
  public UserDetailsService usuarios() {
    UserDetails admin = User.builder()
      .username("admin")
      .password(cifrador().encode("admin123"))
      .roles("ADMIN")
      .build();
    UserDetails docente = User.builder()
      .username("docente")
      .password(cifrador().encode("docente123"))
      .roles("USER")
      .build();
    return new InMemoryUserDetailsManager(admin, docente);
  }

  @Bean
  public PasswordEncoder cifrador() {
    return new BCryptPasswordEncoder();
  }
}
Explica con una frase: ¿por que las contrasenas van cifradas?

Ejercicio 4 — Renderizado condicional

En lista.html, agrega el namespace y condicionales:

<html xmlns:th="http://www.thymeleaf.org"
      xmlns:sec="http://www.thymeleaf.org/extras/spring-security">

<!-- Barra de navegacion -->
<nav>
  <span sec:authorize="isAuthenticated()">
    Hola, <b sec:authentication="name"></b>
  </span>

  <a sec:authorize="hasRole('ADMIN')"
     href="/recursos/estadisticas">Estadisticas</a>

  <form th:action="@{/logout}" method="post" style="display:inline">
    <button type="submit">Cerrar sesion</button>
  </form>
</nav>

<!-- En la tabla de recursos -->
<tr th:each="r : ${recursos}">
  <td th:text="${r.titulo}"></td>
  <td th:text="${r.tipo}"></td>
  <td sec:authorize="hasRole('ADMIN')">
    <a th:href="@{/recursos/borrar/{id}(id=${r.id})}">
      Borrar
    </a>
  </td>
</tr>
Prueba
Inicia como admin: debes ver "Borrar" y "Estadisticas". Inicia como docente: no deben aparecer.

Ejercicio 5 — Consultas personalizadas

Agrega metodos al repositorio:

public interface RecursoDidacticoRepositorio
    extends JpaRepository<RecursoDidactico, Long> {

  List<RecursoDidactico> findByTipo(String tipo);
  List<RecursoDidactico> findByTituloContainingIgnoreCase(
      String palabra);
  long countByTipo(String tipo);
}

Modifica el controlador para aceptar filtros:

@GetMapping
public String listar(
    @RequestParam(required = false) String tipo,
    @RequestParam(required = false) String buscar,
    Model model) {

  List<RecursoDidactico> recursos;
  if (tipo != null && !tipo.isEmpty()) {
    recursos = repo.findByTipo(tipo);
  } else if (buscar != null && !buscar.isEmpty()) {
    recursos = repo.findByTituloContainingIgnoreCase(buscar);
  } else {
    recursos = repo.findAll();
  }
  model.addAttribute("recursos", recursos);
  return "recursos/lista";
}

Ejercicio 7 — Ruta de estadisticas

En el controlador:

@GetMapping("/estadisticas")
public String estadisticas(Model model) {
  model.addAttribute("videos", repo.countByTipo("Video"));
  model.addAttribute("libros", repo.countByTipo("Libro"));
  model.addAttribute("articulos", repo.countByTipo("Articulo"));
  model.addAttribute("total", repo.count());
  return "recursos/estadisticas";
}

Ejercicio 9 — Consola H2 y verificacion

Ejercicio 10 — Diagnostico de errores

Resuelve usando el flujo de 4 pasos:

  1. Leer el mensaje del log/navegador.
  2. Identificar archivo o ruta mencionada.
  3. Comparar con la configuracion de seguridad y el controlador.
  4. Reintentar y documentar.
Error 403
¿El usuario tiene login pero no el rol correcto? Revisa las reglas en SeguridadConfig.
Login loop
¿Olvidaste .permitAll() en la ruta de login?
sec: no funciona
¿Falta la dependencia thymeleaf-extras-springsecurity6 o el namespace xmlns:sec?
