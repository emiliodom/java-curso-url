Dependencias de seguridad (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

<dependency>
    <groupId>org.thymeleaf.extras</groupId>
    <artifactId>thymeleaf-extras-springsecurity6</artifactId>
</dependency>

SecurityConfig.java (mínimo)

@Configuration
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filtro(HttpSecurity http)
            throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/", "/css/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .formLogin(form -> form
                .loginPage("/login")
                .defaultSuccessUrl("/recursos", true)
                .permitAll()
            )
            .logout(logout -> logout
                .logoutSuccessUrl("/login?logout")
                .permitAll()
            );
        return http.build();
    }

    @Bean
    public UserDetailsService usuarios() {
        var user = User.builder()
            .username("docente")
            .password(encoder().encode("1234"))
            .roles("USER").build();
        var admin = User.builder()
            .username("admin")
            .password(encoder().encode("admin123"))
            .roles("ADMIN","USER").build();
        return new InMemoryUserDetailsManager(user, admin);
    }

    @Bean
    public PasswordEncoder encoder() {
        return new BCryptPasswordEncoder();
    }
}

Getters calculados (@Transient)

GetterCódigo¿En BD?

Regla: Si el valor depende de otros campos y cambia dinámicamente → @Transient getter. Nunca lo guardes en BD.

Anotaciones clave de Spring Security

Anotación / Método¿Qué hace?
@ConfigurationMarca la clase como configuración de Spring
@BeanRegistra un objeto en el contenedor de Spring
permitAll()Cualquiera puede acceder (sin login)
authenticated()Solo usuarios con sesión activa
hasRole("ADMIN")Solo usuarios con rol ADMIN
formLogin()Habilita el formulario de login
logout()Habilita la ruta /logout
BCryptPasswordEncoderEncripta contraseñas (nunca texto plano)

Thymeleaf + Security (sec:authorize)

<!-- Solo si está autenticado -->
<span sec:authorize="isAuthenticated()">
  Bienvenido, <span sec:authentication="name"></span>
</span>

<!-- Solo para ADMIN -->
<div sec:authorize="hasRole('ADMIN')">
  <a href="/admin/panel">Panel Admin</a>
</div>

<!-- Solo si NO está autenticado -->
<a sec:authorize="!isAuthenticated()" href="/login">
  Iniciar sesión
</a>

Checklist de QA manual

  1. ✅ App arranca sin errores en localhost
  2. 🔐 Login correcto → entra
  3. ❌ Login incorrecto → muestra error
  4. 📝 Crear registro → se guarda
  5. 📋 Listar registros → se ven
  6. 🧮 Campo calculado → valor correcto
  7. 🔄 Setter transformador → dato limpio
  8. 🚪 Logout → redirige al login
  9. 🛡️ Rol incorrecto → no ve sección protegida
  10. 📱 Responsive → funciona en celular

# 2. QA manual en localhost (checklist)
# 3. Commit descriptivo
