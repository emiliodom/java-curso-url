Archivos de configuración

Dockerfile

Ubicación: raíz del proyecto (junto a pom.xml). Render no tiene Java nativo — necesita este archivo para compilar y ejecutar tu app.

# Etapa 1: Compilar el proyecto
FROM maven:3.9-eclipse-temurin-17 AS build
WORKDIR /app
COPY . .
RUN ./mvnw clean package -DskipTests

# Etapa 2: Ejecutar la aplicación
FROM eclipse-temurin:17-jre
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar
EXPOSE 10000
CMD ["java", "-Xmx256m", "-jar", "app.jar"]
application.properties (producción)
# Puerto dinámico de Render
server.port=${PORT:8080}

# H2 en memoria
spring.datasource.url=jdbc:h2:mem:proddb
spring.datasource.driver-class-name=org.h2.Driver
spring.jpa.hibernate.ddl-auto=update

# Consola H2 accesible remotamente
spring.h2.console.enabled=true
spring.h2.console.settings.web-allow-others=true

¿Por qué Docker? Render solo soporta nativamente Node.js, Python, Ruby, Go, Rust y Elixir. Para Java/Spring Boot necesitas un Dockerfile.

Errores comunes → Soluciones

ErrorCausaSolución
UnsupportedClassVersionError Java incorrecto en Dockerfile Usar eclipse-temurin:17 en ambas etapas del Dockerfile
Port 8080 in use Puerto fijo server.port=${PORT:8080}
Memory exceeded (OOM) Mucha RAM -Xmx256m en CMD del Dockerfile o JAVA_TOOL_OPTIONS
mvnw: Permission denied Sin permisos Agregar RUN chmod +x mvnw en el Dockerfile, o git update-index --chmod=+x mvnw
H2 lock error H2 en archivo Cambiar a jdbc:h2:mem:proddb
App tarda en responder (cold start) Plan free "duerme" tras 15 min sin tráfico entrante Normal (~30-60s). Un @Scheduled interno NO cuenta. Workaround: cron externo con cron-job.org cada 14 min.
💡 Tip — Evitar el cold start:
Render cuenta solo el tráfico entrante (inbound HTTP), no la actividad interna del proceso. Un @Scheduled en Spring no impide el spin-down.
Solución: crea un cron externo en cron-job.org (gratis) que haga GET a tu URL de Render cada 14 minutos.

Flujo completo en 6 pasos

  1. ✅ App funciona en localhost:8080
  2. � Crear Dockerfile multi-stage (compilar + ejecutar con Java 17)
  3. ⚙️ Ajustar application.properties → puerto dinámico + H2 en memoria
  4. 📤 git add . → git commit → git push
  5. 🌐 Crear Web Service en Render → Language: Docker → seleccionar repo
  6. 🎉 URL pública activa → verificar en celular
